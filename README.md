# Ajolocoin

Ajolocoin es una base mínima para construir una criptomoneda en la red Atom usando Cosmos SDK. 
Cada token acuñado incluye una característica de un ajolote, como color, tamaño o tipo de branquias.

## Uso

Para acuñar un token de Ajolocoin, ejecuta:

```
go run ./cmd/ajolocoincli <id> <caracteristica>
```

Esto creará un token en memoria con el identificador y la característica proporcionados.
